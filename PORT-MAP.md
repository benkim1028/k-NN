## Format Decisions Locked By The Brief

- Read per-ordinal centroid assignments from existing `.clac` region 1; do not add `.claf`.
- Do not change any written bytes in `.clam`, `.clac`, `.clap`, or `.clar`.
- Use ord-to-doc translation from this tree for every filtered exact or assignment path; never assume `ord == docID`.

## Known Open Questions To Record Later In `DECISIONS.md`

- The design doc says `log2(1 + count)` while the POC code uses `log1p(count)`; the port should follow the POC and surface the discrepancy.
- The POC's block-level skip only applies to non-EUCLIDEAN scoring; parity does not imply EUCLIDEAN gets the same optimization.
